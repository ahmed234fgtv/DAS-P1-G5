# Requisitos del sistema

## Requisitos funcionales

Tabla 1. Requisitos funcionales identificados en el Anexo I.

| Identificador | Nombre | Descripción |
| --- | --- | --- |
| RF01 | Diferenciación del tipo de cliente | El sistema deberá distinguir entre los clientes que acceden desde un PC y aquellos que acceden desde una tablet. |
| RF02 | Suscripción a noticias | El sistema deberá permitir a los lectores suscribirse de manera anónima a diferentes noticias. Las noticias podrán ser de política, economía, sociedad, nacionales o internacionales. |
| RF03 | Baja de suscripciones a noticias | El sistema deberá permitir a los suscriptores darse de baja de sus suscripciones a noticias de manera anónima. |
| RF04 | Gestión de modalidades de facturación | El sistema deberá gestionar tres modalidades de facturación: trimestral, con un pago recurrente de 70 € cada tres meses (descuento base); semestral, con un pago recurrente de 130 € cada seis meses (descuento intermedio); y anual, con un pago recurrente de 190 € cada doce meses (máximo ahorro mensual). |
| RF05 | Gestión de pagos online | El sistema deberá gestionar los pagos online correspondientes a las modalidades de facturación establecidas. |
| RF06 | Reintentos de pagos fallidos | Cuando falle una petición de pago, el sistema deberá permitir reintentar dicho pago hasta un máximo de tres veces. |
| RF07 | Estadísticas de noticias más leídas | El sistema deberá proporcionar a los administradores y redactores estadísticas que permitan identificar las noticias más leídas. |
| RF08 | Estadísticas de tiempo de permanencia | El sistema deberá proporcionar a los administradores y redactores estadísticas sobre el tiempo de permanencia de los usuarios. |
| RF09 | Estadísticas de tasa de rebote | El sistema deberá proporcionar a los administradores y redactores estadísticas sobre las tasas de rebote. |
| RF10 | Estadísticas de conversión | El sistema deberá proporcionar a los administradores y redactores estadísticas sobre la conversión de lectores a suscriptores. |

**Nota:** Las indicaciones sobre HTTP/REST, Stripe y PostgreSQL 19 son restricciones tecnológicas del enunciado y no se han formulado como requisitos funcionales independientes.

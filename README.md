# DAS - Práctica 1

**Captura y Representación de Decisiones de Diseño**  
Grado en Ingeniería del Software · Curso 2026-2027

El caso de estudio consiste en diseñar la arquitectura de un periódico digital con suscripciones, pagos y estadísticas de uso.

## Organización del repositorio

- **Requisitos:** requisitos funcionales y de dominio del sistema.
- **Decisiones:** decisiones arquitectónicas documentadas en formato MADR.
- **Arquitecturas:** diagramas de clases y paquetes UML resultantes de las decisiones de diseño.

Las decisiones se guardan en archivos Markdown numerados consecutivamente, con nombres como `0001-seleccion-estilo-arquitectonico.md`. Para crear una nueva decisión se parte de `Decisiones/adr-template.md` y se completa con las alternativas y la justificación acordadas por el grupo.

Los requisitos, las decisiones y los diagramas se actualizarán durante las tres semanas de la práctica, conservando en GitHub los cambios correspondientes a cada iteración.
